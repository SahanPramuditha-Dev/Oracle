# ORACLE project idea

## Current stage

Early development. The browser interface and local backend foundation now work; model setup and AI responses remain deferred. The wider feature scope is still being reviewed. See [development status](../DEVELOPMENT_STATUS.md) for completed work and test evidence.

## Idea

ORACLE is a proposed personal AI assistant inspired by JARVIS. It would combine natural conversation, useful computer actions, camera understanding and approved personal memory. Maps and place context could connect saved information to real locations.

## Examples

- Ask ORACLE to open programs, search for information and find a selected file.
- Point a camera at an object, label or poster and ask about it.
- Save a useful observation and find it later using everyday language.
- Save a parking photo or useful place and retrieve its recorded location.
- Connect these actions, such as reading an event poster and offering to create a reminder.

## What we are exploring

General assistant and desktop functions, voice, productivity, camera interaction, memory, maps and optional specialist features. The feature and scenario registers preserve the complete idea pool; inclusion is not a promise to build everything.

## Design intentions

Keep control of sensors and saved information visible. Show evidence and uncertainty. Ask before consequential actions. Prefer local processing where practical and explain external service use. These intentions will become detailed requirements once scope is agreed.
